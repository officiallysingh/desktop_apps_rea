## Decision factors
| Factor | Separate edition | Combine |
| --- | --- | --- |
| Target user | Different personas | Same user, adjacent jobs |
| Shared data | Little overlap | Same parties, ledgers, stock |
| Pricing / GTM | Different buyers | Upsell path |
| UX complexity | Would bloat navigation | Fits one shell |
