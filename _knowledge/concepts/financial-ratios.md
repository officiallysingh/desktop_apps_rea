# Financial ratios

## In one paragraph
Ratios turn statements into comparable signals: **liquidity** (can it pay short-term bills),
**profitability** (relative to size), **leverage** (debt vs owners' money) and **turnover**
(how efficiently assets are used).

## Formulas
| Ratio | Formula | Reading |
| --- | --- | --- |
| Current ratio | Current assets / Current liabilities | Higher = more liquid [AMS ch.6] |
| Quick ratio | (Current assets − Inventory) / Current liabilities | Excludes stock [AMS ch.6] |
| Working capital | Current assets − Current liabilities | A cushion; judge against cash-flow needs [ANA ch.8] |
| Quick (acid-test) assets | Current assets − Inventory − Prepaid items | Stricter than AMS definition [ANA ch.8] |
| Return on assets | Net income / Total assets | Profit vs size [AMS ch.6] |
| Return on equity | Net income / Owners' equity | Return to owners [AMS ch.6] |
| Gross profit margin | Gross profit / Sales | Compare within an industry only [AMS ch.6] |
| Debt ratio | Total liabilities / Total assets | Share financed by debt [AMS ch.6] |
| Debt-to-equity | Total liabilities / Owners' equity | Leverage raises ROE and risk [AMS ch.6] |
| Inventory turnover | COGS / Average inventory; average = (opening + closing)/2 | Higher = faster selling [AMS ch.6; ANA ch.8] |
| Inventory period (days) | 365 / Inventory turnover | |
| Receivables turnover | Credit sales / Average receivables | [AMS ch.6] |
| Average collection period (days) | 365 / Receivables turnover | Lower is better |

## More ratios [FADM ch.8]
| Ratio | Formula |
| --- | --- |
| ROCE (return on capital employed) | Operating profit / (Equity + Non-current liabilities) |
| ROSF (return on shareholders' funds) | Profit for the year (after tax, pref. dividends) / Ordinary equity |
| Operating profit margin | Operating profit / Sales |
| Inventory turnover period (days) | Average inventory / COGS × 365 |
| Receivables settlement period (days) | Average trade receivables / Credit sales × 365 |
| Payables settlement period (days) | Average trade payables / Credit purchases × 365 |
| Sales to capital employed | Sales / Capital employed |
| Sales per employee | Sales / Number of employees |
| Cash generated to maturing obligations | Operating cash flow / Current liabilities |
| Operating cash cycle (days) | Inventory days + Receivable days − Payable days |
| Gearing | Long-term (non-current) liabilities / (Equity + Non-current liabilities) |
| Interest cover | Operating profit / Interest payable |
- Ratios need a benchmark: past periods, similar businesses or plan; interpret with caution. [FADM ch.8]
- Working capital management aims to shorten the operating cash cycle without undue risk. [FADM ch.8]

## Rules of thumb (vary by industry; compare with own history and industry peers)
- Current ratio > 2.0; quick ratio ≥ 1.5 (one source's guide; too high can mean idle cash). [ANA ch.8]
- Ratios are used by outsiders: bankers (current ratio, working capital) for loans; suppliers
  (quick ratio) for credit. [ANA ch.8]
- Long-term analysis adds quality of earnings, return on investment, sales-based percentages
  (each expense as % of sales), long-term debt position and dividend data. [ANA ch.9]

  ratio for traders and distributors.

- Common-size P&L (each line as % of sales) with period comparison.
- A dashboard of these ratios per period with trend, computed from the ledger (no manual input).
- Party-level versions are more useful to SMBs: days-sales-outstanding per customer, ageing,
  slow-moving items (inventory days per item).
- AI assistant can explain ratio changes in plain language (later feature).
